# PythonWorkshop

Voor de eerste python assignment heb ik een code geschreven waarmee willekeurig sensor waarden kan worden gegenereerd voor verschillende sensoren
Wanneer het programma wordt gestart, krijgt de gebruiker twee keuzemogelijkheden:

Genereer willekeurige sensormetingen:
Toon eerder opgeslagen sensormetingen:

Optie 1: Genereer willekeurige sensormetingen
Wanneer de gebruiker optie 1 kiest, vraagt het programma om verschillende invoergegevens, waaronder:
Sensortype
Minimale waarde
Maximale waarde
Aantal metingen (readings)
Drempelwaarde (threshold)

Nadat de gebruiker alle benodigde gegevens heeft ingevuld, genereert het programma willekeurige sensormetingen binnen het opgegeven bereik.
De gegenereerde gegevens worden vervolgens weergegeven in twee tabellen:

Sensor Readings: Geeft alle afzonderlijk gegenereerde sensorwaarden weer.
Sensor Reading Distribution: Geeft de verdeling van de gegenereerde sensorwaarden weer.

Optie 2: Toon eerder opgeslagen sensormetingen

Wanneer de gebruiker optie 2 kiest, worden de eerder gegenereerde en opgeslagen sensormetingen weergegeven.
Hierdoor kan de gebruiker eerder verzamelde sensorgegevens bekijken zonder opnieuw willekeurige waarden te hoeven genereren.
